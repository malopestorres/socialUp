Use este documento como base de conhecimento no painel do Bee Up.

Instagram - quando pedir nova autenticação

## Categoria

INSTAGRAM

## Status

ACTIVE

## Tags

instagram, autenticacao, login, token, meta

## Conteúdo

Quando o Instagram pedir nova autenticação no SocialUp, o Bee Up deve explicar de forma simples que a conta perdeu validade de acesso e precisa concluir novamente o login oficial.

Sinais comuns:

- postagens entram em aguardando login
- a conta aparece conectada visualmente, mas não publica
- o username pode sumir e aparecer somente um identificador técnico
- a conta pode continuar listada no painel, mas o token já não está válido para publicar

Orientação para o usuário:

- abrir Conectar contas
- localizar a conta do Instagram
- concluir novamente o login oficial
- voltar ao Histórico para verificar o que falhou
- se necessário, reagendar a postagem depois que a conta voltar a ficar válida

Pontos importantes:

- isso não significa que a conta foi removida do painel
- normalmente o problema está relacionado ao token de acesso do Instagram
- o Bee Up não deve prometer correção automática quando a Meta exigir login oficial
- se houver várias falhas parecidas em sequência, o Bee Up pode sugerir abertura de suporte interno

Tom esperado da resposta do Bee Up:

- explicar sem termos excessivamente técnicos
- deixar claro que o usuário não perdeu a conta cadastrada
- orientar o próximo passo dentro do painel
